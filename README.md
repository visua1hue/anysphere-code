# Anysphere Code

Cursor's Anysphere theme for [VS Code](https://code.visualstudio.com) and [T3 Code](https://t3.codes), reworked with a near-black background and muted grays.

## Install in VS Code

1. Download the `.vsix` file from the [latest release](https://github.com/visua1hue/anysphere-code/releases/latest).
2. In VS Code, open the Extensions view, click "..." and choose "Install from VSIX...".
3. Pick "Anysphere Code" under Preferences > Color Theme.

## Install in T3 Code

1. Download [`t3code/anysphere-code.json`](t3code/anysphere-code.json).
2. In T3 Code, open Settings > Appearance and import the file.
3. Pick "Anysphere Code" as the theme.
